# SF Airbnb Listings

A simple, static web page that loads San
Francisco Airbnb listing data from a local JSON file and displays the
first 50 listings as cards, using HTML, CSS, and JavaScript.

## Live site: https://jharshini97.github.io/java_dom_self-assessment/

Each listing card shows:
- Thumbnail photo
- Name
- Description
- A selection of amenities (with a "+N more" count)
- Host name and host photo
- Price per night

**Creative addition:** a **Superhost badge** is automatically shown on
any card where the host data marks them as a Superhost.

## Data source

`airbnb_sf_listings_500.json` contains San Francisco Airbnb listing data (based on
publicly available Inside Airbnb-style data) provided for this assignment.
